# Tutor-quirurgico

Simulador de instrumental quirúrgico para estudiar el temario de instrumental del Màster en Infermeria Quirúrgica (UB IFContinua-IL3).

## Versión actual: `simulador/`

```
simulador/
├── index.html   ← el simulador
├── img/         ← las 57 imágenes del modo visual
└── LEEME.txt    ← instrucciones de uso
```

### Cómo abrirlo

1. Descarga o clona el repositorio. Si lo bajas como ZIP, descomprímelo entero (botón derecho → «Extraer todo»).
2. Abre `simulador/index.html` con el navegador (Chrome, Edge, Firefox o Safari).
3. Deja la carpeta `img` junto a `index.html`. Si falta, el modo visual muestra un aviso.

Funciona sin internet. En el móvil, abrir un HTML descargado no suele cargar las imágenes: usa el ordenador o una versión publicada como página web.

### Qué incluye

| Modo | Contenido |
|---|---|
| Test | 231 preguntas en 16 temas |
| Casos clínicos | 82 casos en 7 especialidades |
| Diálogo clínico | 14 escenas con preguntas en el momento del error |
| Fichas | 56 instrumentos con función, rasgo visual y perla clínica |
| Comparativas | 12 pares de instrumentos que se confunden |
| Errores frecuentes | 20 errores conceptuales corregidos |
| Identificación visual | 57 imágenes reales, en quiz o en galería |

### Funciones de estudio

- **Perfil de aprendizaje** en el test y en los casos: porcentaje de aciertos por tema o especialidad y temas a reforzar.
- **Repaso dirigido**: abre el tema más débil y prioriza las preguntas falladas, después las no vistas y por último las acertadas.
- **Repasar mis fallos**: test o serie de casos con los fallos pendientes de todos los temas.
- **Galería** con ficha de cada instrumento (imagen, nombre, grupo y descripción).

El progreso se guarda en el navegador de cada dispositivo. No se comparte entre dispositivos y se pierde si se borran los datos del navegador.

### Revisión del contenido

- Las opciones de respuesta están equilibradas en longitud: la correcta ya no se distingue por ser la más larga.
- Se han eliminado las preguntas duplicadas dentro de cada tema.
- El contenido se ha contrastado con el temario «Instrumental quirúrgic» (Ana Fernández Vargas). Las partes que el temario no cubre (energía, técnica laparoscópica, suturas, microcirugía y casos por especialidad) requieren revisión clínica.
