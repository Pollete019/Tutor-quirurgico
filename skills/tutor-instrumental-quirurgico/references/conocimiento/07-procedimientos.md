# Procedimientos: sets y secuencia de instrumental

Base para el modo **Simulación de quirófano**. Cada procedimiento: set, material específico, secuencia (paso → lo que pide el cirujano → lo que el instrumentista entrega/anticipa) y puntos críticos. Las técnicas y preferencias varían entre centros y cirujanos: la secuencia es **típica**, no única. Si el alumno propone una alternativa razonable, valórala por su lógica.

## Sets base (contenido orientativo)
- **Set de cirugía menor / básico**: mango de bisturí 3, tijeras Mayo y Metzenbaum, pinzas de disección con y sin dientes, Adson, mosquitos, Kelly/Crile, Allis, Farabeuf, Senn-Miller, portaagujas, pinzas de campo.
- **Set de laparotomía**: el básico + mango 4, tijeras largas, hemostáticas largas (Kelly largas, Rochester, Kocher), Mixter, Babcock, Allis largas, Foerster, separadores Richardson, Deaver, valva maleable, autoestático (Balfour/Gosset), portaagujas largos, cánulas Yankauer y Poole.
- **Set de laparoscopia**: ver `06-laparoscopia-robotica.md`.
- **Set de vascular**, **trauma**, **neuro**, **micro**: ver `04-especialidades.md`.

## 1. Laparotomía media (apertura y cierre)
| Paso | Instrumental |
|---|---|
| Incisión cutánea | Bisturí (mango 4, hoja 20–23, o mango 3 hoja 10) + gasas |
| Tejido subcutáneo y hemostasia | Electrobisturí, pinzas de disección con dientes, Farabeuf |
| Línea alba | Bisturí/electrobisturí; Kocher para traccionar la aponeurosis |
| Apertura del peritoneo | Dos pinzas (Kelly/mosquitos) levantan el peritoneo; el cirujano palpa que no hay víscera; bisturí o **Metzenbaum**, ampliar con tijera protegiendo con los dedos |
| Exposición | Compresas húmedas, separador autoestático (Balfour/Gosset/Omnitract), valvas |
| **Recuento antes del cierre** | Gasas, compresas, agujas, instrumental: **antes de cerrar peritoneo/aponeurosis** |
| Cierre de aponeurosis | Portaagujas largo + **PDS 1 (lazo)** o equivalente, **valva maleable** protegiendo vísceras, Kocher en los extremos |
| Subcutáneo | (Opcional) Vicryl 2-0/3-0 |
| Piel | Grapadora cutánea o sutura (nylon 3-0 con aguja de piel, intradérmica Monocryl 3-0/4-0) |
| **Recuento final** | Al cierre de piel |
- Puntos críticos: dos recuentos de cierre; valva maleable retirada **antes** de anudar el último punto.

## 2. Apendicectomía abierta (McBurney)
| Paso | Instrumental |
|---|---|
| Incisión en fosa ilíaca derecha | Bisturí hoja 10/20, Farabeuf |
| Aponeurosis del oblicuo externo | Bisturí + Metzenbaum/Mayo, Kocher |
| Divulsión muscular (oblicuo interno, transverso) | Dos pinzas (Kelly) y **separadores de Farabeuf/Richardson** (divulsión en el sentido de las fibras) |
| Peritoneo | Dos mosquitos/Kelly + Metzenbaum |
| Exteriorizar apéndice | **Babcock** (atraumática) sobre el apéndice / ciego |
| Mesoapéndice | Mosquitos/Kelly, Metzenbaum, ligaduras (Vicryl 2-0/3-0) o energía |
| Base apendicular | Pinza (Kocher/Kelly) para aplastar la base, ligadura (Vicryl 0/2-0), sección con **bisturí** (se considera **material contaminado**) |
| Muñón | (Opcional) jareta con Vicryl 3-0 e invaginación; povidona sobre el muñón según escuela |
| Tras la sección | **Retirar el material contaminado** (bisturí, pinzas que tocaron la luz), a una batea aparte; cambio de guantes según protocolo |
| Cierre por planos | Vicryl, piel |
- Pieza a Anatomía Patológica; si hay pus: **cultivo** (torunda/jeringa) antes de irrigar.

## 3. Apendicectomía laparoscópica
Trócares (umbilical 10–12, suprapúbico 5, FII 5–12) → exploración → grasper atraumático sobre el apéndice → disección del meso con Maryland/energía (LigaSure/Harmonic) o clips → base con **endoloops** (ligaduras preanudadas) o **endograpadora** → extracción en **bolsa** → irrigación-aspiración si peritonitis → cierre de orificios.

## 4. Colecistectomía laparoscópica
| Paso | Instrumental |
|---|---|
| Neumoperitoneo | Veress (o Hasson) + insuflador 12–15 mmHg |
| Trócares | Umbilical 10 mm (óptica 30°), epigástrico 10–12 mm, dos de 5 mm subcostales |
| Exposición | **Grasper traumático/de vesícula** en fundus (tracción craneal) e infundíbulo (tracción lateral) |
| Disección del triángulo hepatocístico | **Maryland** y **gancho** monopolar |
| **Visión crítica de seguridad** | Sin CVS no se clipa |
| Clipado | **Aplicador de clips** (2 proximales y 1 distal en cístico y arteria) |
| Sección | **Tijera laparoscópica** entre clips |
| Separación del lecho | Gancho / espátula monopolar |
| Revisión | Hemostasia, irrigación-aspiración |
| Extracción | **Endobag** por trocar umbilical/epigástrico |
| Cierre | Fascia de orificios de 10–12 mm (aguja 5/8 o en J), piel |
- Material de conversión (laparotomía subcostal) localizado; posible **colangiografía intraoperatoria** (catéter, contraste, arco en C).

## 5. Hernioplastia inguinal (Lichtenstein)
Incisión inguinal (bisturí 10/15) → subcutáneo (Farabeuf) → aponeurosis del oblicuo externo (Metzenbaum), referencia con mosquitos → **aislar el cordón** con Penrose o vessel loop → disección del saco herniario (Metzenbaum, disección de dientes finos/Adson), **alta ligadura/resección o invaginación** del saco → **malla de polipropileno** recortada (cambio de guantes o manipulación mínima, sin contacto con piel) fijada con **polipropileno 2-0/3-0** (monofilamento no absorbible) al ligamento inguinal (Poupart) y tendón conjunto → cierre del oblicuo externo (Vicryl 2-0) → subcutáneo → piel (intradérmica).
- Estructuras a proteger: **nervios ilioinguinal, iliohipogástrico y rama genital del genitofemoral**; conducto deferente y vasos del cordón (no pinzarlos con instrumental traumático).

## 6. Tiroidectomía total
Posición en hiperextensión cervical → incisión de Kocher (bisturí 15/10) → colgajos subplatismales (pinzas de piel/ganchos, electrobisturí, **separador autoestático de Weitlaner** o Joll) → separación de la musculatura pretiroidea (**Langenbeck/Farabeuf**, Kelly) → luxación del lóbulo (**pinza de Lahey**, Babcock) → ligadura de polos (Mixter, mosquitos, ligaduras 2-0/3-0, clips o **bipolar/Harmonic/LigaSure**) → **identificación del nervio laríngeo recurrente** (bipolar/energía de baja dispersión térmica; **neuromonitorización** con estimulador) y **paratiroides** (preservar su vascularización; autotrasplante si se extirpan inadvertidamente) → hemostasia (hemostáticos tópicos) → drenaje (opcional) → cierre de pretiroideos (Vicryl 3-0), platisma, piel (intradérmica 4-0/5-0 o grapas finas).
- Pieza: marcar lóbulos según indique el cirujano.

## 7. Hemicolectomía derecha / anastomosis intestinal (abierta)
Laparotomía → exposición (autoestático, compresas) → movilización del colon (Metzenbaum, **Babcock** sobre intestino) → ligadura de pedículos (Mixter, Kelly largas, ligaduras/energía) → sección intestinal con **GIA** (o clamps intestinales: **Doyen** atraumáticos en el lado que queda + **Kocher/Payr** traumáticos en el lado de la pieza) → anastomosis ileocólica (latero-lateral mecánica con **GIA + TA/GIA** para cerrar el orificio, o manual con Vicryl/PDS 3-0) → cierre del defecto mesentérico.
- **Técnica aséptica de anastomosis**: el instrumental que contacta con la **luz intestinal** se aísla en una batea y se retira; cambio de guantes y de paños/compresas perianastomóticas según protocolo antes del cierre.
- Registrar cargas de grapadora.

## 8. Mastectomía / cirugía de mama y ganglio centinela
Detección del **ganglio centinela** (sonda gamma con funda estéril; colorante azul/verde de indocianina) → incisión (bisturí 10/15) → colgajos (**pinzas de Allis** o ganchos de piel para traccionar el borde, electrobisturí, **Farabeuf/Langenbeck**) → exéresis del ganglio o pieza → **orientación de la pieza con puntos/clips** según indique el cirujano (márgenes) → hemostasia → drenaje aspirativo (Redon/Blake) → cierre (Vicryl subcutáneo, Monocryl intradérmico).
- Biopsia intraoperatoria en fresco (sin formol), identificada y enviada inmediatamente.

## 9. Cesárea
Pfannenstiel (bisturí 20/10) → aponeurosis (bisturí, Mayo curva, Kocher) → separación de rectos (dedos, Kelly) → peritoneo (dos pinzas + Metzenbaum) → **valva suprapúbica (Doyen)** → histerotomía segmentaria (bisturí + ampliación digital o con tijera) → extracción fetal → **pinzado y corte del cordón** (dos pinzas —Kocher/Kelly— y tijera; muestra de sangre de cordón) → alumbramiento → histerorrafia (Vicryl 1 o equivalente, portaagujas largo, pinzas de Foerster/Allis en los ángulos si hace falta) → revisión → cierre por planos.
- Recuento **antes del cierre uterino**, antes de cerrar la pared y al final (cavidad dentro de cavidad).
- Preparación paralela para la reanimación neonatal (no es rol del instrumentista pero debe coordinarse).

## 10. Artroplastia total de cadera
Posición (decúbito lateral) → incisión (bisturí 20–22) → fascia lata (Mayo, electrobisturí) → exposición (**Hohmann**, separador autoestático tipo Charnley) → capsulotomía → luxación → **osteotomía del cuello femoral** (sierra oscilante) → extracción de la cabeza (sacacabezas) → **acetábulo**: fresado con **fresas acetabulares de tamaño creciente** con motor → **cotilo de prueba** → cotilo definitivo (± tornillos acetabulares con broca/medidor) → inserto → **fémur**: punzón/escoplo de apertura, **raspas** de tamaño creciente → **vástago y cabeza de prueba** → reducción de prueba (estabilidad, longitud) → componentes definitivos (± **cemento**: avisar a anestesia) → reducción → cierre por planos (± drenaje).
- Confirmar **tamaño y lado** antes de abrir cada implante definitivo; registrar etiquetas; lavado pulsátil; profilaxis de infección (restricción de puertas).

## 11. Osteosíntesis de tobillo (fractura bimaleolar)
Isquemia → incisión lateral (bisturí 15/10) → exposición del peroné (**Senn-Miller, Farabeuf, Hohmann pequeños**, legra) → limpieza del foco (cucharilla, irrigación) → **reducción** (pinza de reducción puntiaguda/**pinza maleolar**, Kirschner provisional) → **placa de tercio de tubo** (o anatómica) → tornillos: **broca 2,5 → medidor → macho 3,5 → tornillo cortical 3,5**; esponjosos distales; tornillo interfragmentario → control con **arco en C** → maléolo medial: reducción, tornillos canulados/esponjosos 4,0 o agujas + cerclaje en obenque → cierre (Vicryl, nylon/grapas).
- Leer en voz alta la medida y confirmar el tornillo; anotar tiempo de isquemia.

## 12. Enclavado endomedular de fémur
Tracción/mesa ortopédica → incisión proximal → **punzón de entrada** (fosa piriforme/trocánter según clavo) → **aguja guía de punta de oliva** bajo escopia → **fresado** progresivo (fresas flexibles, 0,5 mm cada vez) → medición de longitud → **clavo** montado en su guía → **bloqueo proximal** (con guía) → **bloqueo distal** (manos libres bajo escopia o guía) → tapón → cierre.
- Registrar tamaño del clavo y tornillos; protección radiológica.

## 13. Craneotomía supratentorial
Fijación con **Mayfield** → incisión (bisturí 10/20) → **clips de Raney** (hemostasia del cuero cabelludo) con su aplicador, **ganchos/separadores de colgajo** → despegamiento del pericráneo (**legra/periostótomo**) → trépanos con **perforador** → **craneotomo** con pie protector → elevación del colgajo óseo (Penfield 3, disectores) → hemostasia ósea (**cera de hueso**) y dural (**bipolar**, Surgicel, lentinas) → **durotomía** (bisturí 11/15, gancho dural, tijera de dura) → procedimiento bajo **microscopio** (bipolar en bayoneta, **aspirador Frazier**, **espátulas**, microtijeras) → cierre de dura (Prolene/Vicryl 4-0, sustituto dural) → reposición del hueso (**miniplacas y tornillos de titanio** o puntos transóseos) → galea (Vicryl 2-0/3-0) → piel (grapas/nylon).
- Recuento de **lentinas**; todo el equipo sabe dónde están los clips de aneurisma si es cirugía vascular.

## 14. Discectomía / laminectomía lumbar
Posición prona → incisión (bisturí 10/20) → fascia → disección subperióstica (**Cobb**, electrobisturí) → separador autoestático (**Gelpi**, Weitlaner, Caspar/Taylor) → localización del nivel con escopia (aguja de referencia) → **Kerrison** para lámina y ligamento amarillo, **Leksell** para hueso → protección de raíz/dura (**separador de raíz**, disectores Penfield) → **anulotomía (bisturí 11/15)** → **pinzas de disco (hipofisarias)** para extraer el fragmento → irrigación, hemostasia (bipolar, cera, Gelfoam) → cierre por planos.
- Riesgo de desgarro dural (preparar sutura dural fina y sellante).

## 15. Endarterectomía carotídea
Incisión cervical (bisturí 15/10) → disección (Metzenbaum, bipolar, Weitlaner) → **control con vessel loops** de carótida común, interna y externa → **heparina** (anestesia) → clampaje (clamps **DeBakey/angulados**, Bulldog en externa) **anotando la hora** → arteriotomía (**hoja 11 + Potts**) → **shunt** (si se indica) → **espátula de endarterectomía** para retirar la placa → sutura/parche con **Prolene 6-0 doble aguja** (y parche) → purgado y desclampaje secuencial (externa, común, interna) → hemostasia → drenaje → cierre.

## 16. Toracotomía posterolateral / lobectomía
Decúbito lateral → incisión (bisturí 20) → sección muscular (electrobisturí) → **legra costal (Doyen/Alexander)** → apertura pleural (Metzenbaum) → **Finochietto** → disección hiliar (**Mixter**, disectores largos, **Duval** sobre el pulmón) → sección de vasos (**endograpadora carga vascular** o ligadura) y del bronquio (**TA/grapadora**) → **prueba de estanqueidad** (suero templado + insuflación) → drenajes torácicos → **aproximador costal** + pericostales (Vicryl 1 o 2) → cierre muscular y piel.
