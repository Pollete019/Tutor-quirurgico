# Comparativas entre instrumentos similares

## Mayo vs Metzenbaum
- **En común:** Ambas son tijeras de corte y disección.
- **Diferencia visual:** Mayo: hojas robustas y anchas. Metzenbaum: hojas finas y largas.
- **Diferencia funcional:** Mayo para tejido grueso (fascia, músculo). Metzenbaum para tejido delicado.
- **Error típico:** Pensar que solo cambia el tamaño.
- **Regla para recordar:** Necesitas fuerza → Mayo. Precisión → Metzenbaum.

## Kelly vs Crile
- **En común:** Ambas son hemostáticas curvas con cremallera.
- **Diferencia visual:** Kelly: estriado en mitad distal. Crile: estriado en toda la mandíbula.
- **Diferencia funcional:** Funcionalmente similares; Crile ofrece más agarre total.
- **Error típico:** Decir que son idénticas.
- **Regla para recordar:** Media mandíbula estriada = Kelly. Completa = Crile.

## Adson con dientes vs sin dientes
- **En común:** Ambas son pinzas cortas para sujeción fina.
- **Diferencia visual:** Con dientes: punta con 1×2 dientes visibles. Sin dientes: punta lisa.
- **Diferencia funcional:** Con dientes = piel. Sin dientes = mucosa, vasos, tejidos delicados.
- **Error típico:** Decir que todas las Adson son iguales.
- **Regla para recordar:** ¿Ves dientes en la punta? = con dientes. Lisa = sin dientes.

## Babcock vs Duval
- **En común:** Ambas son de prensión atraumática para vísceras.
- **Diferencia visual:** Babcock: anillo fenestrado oval. Duval: punta triangular.
- **Diferencia funcional:** Babcock = vísceras huecas. Duval = pulmón, hígado.
- **Error típico:** Usarlas como si fueran intercambiables.
- **Regla para recordar:** Oval = Babcock. Triángulo = Duval.

## Satinsky vs Bulldog
- **En común:** Ambos son clamps vasculares.
- **Diferencia visual:** Satinsky: grande, mandíbula curva larga. Bulldog: pequeño, con resorte.
- **Diferencia funcional:** Satinsky = clampaje parcial de vasos grandes. Bulldog = oclusión total de vasos pequeños.
- **Error típico:** Usarlos indistintamente.
- **Regla para recordar:** Grande + flujo mantenido = Satinsky. Pequeño + oclusión total = Bulldog.

## Finochietto vs Balfour
- **En común:** Ambos son separadores autoestáticos con cremallera.
- **Diferencia visual:** Finochietto: diseño costal robusto. Balfour: diseño abdominal con valva central.
- **Diferencia funcional:** Finochietto = tórax. Balfour = abdomen.
- **Error típico:** Usarlos en la cavidad equivocada.
- **Regla para recordar:** Costillas = Finochietto. Abdomen = Balfour. No son intercambiables.

## Deaver vs Harrington
- **En común:** Ambos son separadores manuales abdominales.
- **Diferencia visual:** Deaver: largo y amplio. Harrington: más corto, forma de pala.
- **Diferencia funcional:** Deaver = retracción visceral profunda. Harrington = exposición localizada.
- **Error típico:** Dar Deaver cuando el campo es pequeño.
- **Regla para recordar:** Profundidad y amplitud = Deaver. Campo delimitado = Harrington.

## Monopolar vs Bipolar
- **En común:** Ambos son sistemas de energía eléctrica.
- **Diferencia visual:** Monopolar: un cable + placa neutra. Bipolar: dos cables en el instrumento.
- **Diferencia funcional:** Monopolar: campos amplios. Bipolar: coagulación localizada y segura.
- **Error típico:** Usar monopolar cerca de nervios.
- **Regla para recordar:** Cerca de nervios = bipolar. Campos amplios sin estructuras en riesgo = monopolar.

## Portaagujas Mayo-Hegar vs Castroviejo
- **En común:** Ambos son portaagujas con mecanismo de bloqueo.
- **Diferencia visual:** Mayo-Hegar: mandíbulas anchas. Castroviejo: mandíbulas finas, resorte.
- **Diferencia funcional:** Mayo-Hegar: suturas 0 a 3-0. Castroviejo: 5-0 a 9-0.
- **Error típico:** Suturar vasos con el Mayo-Hegar (demasiado tosco).
- **Regla para recordar:** Grueso = Mayo-Hegar. Fino + resorte = Castroviejo.

## Gelpi vs Finochietto
- **En común:** Ambos son autoestáticos.
- **Diferencia visual:** Gelpi: puntas agudas pequeñas. Finochietto: palas costales masivas.
- **Diferencia funcional:** Gelpi: incisiones pequeñas/profundas. Finochietto: toracotomía.
- **Error típico:** Llamar Gelpi a cualquier autoestático.
- **Regla para recordar:** Puntas agudas + pequeño + profundo = Gelpi.

## Foerster vs Babcock
- **En común:** Ambas tienen anillos fenestrados.
- **Diferencia visual:** Foerster: dos anillos redondos. Babcock: un anillo oval.
- **Diferencia funcional:** Foerster = sujetar gasas. Babcock = sujetar vísceras huecas.
- **Error típico:** Usar el Foerster para intestino.
- **Regla para recordar:** Dos anillos = Foerster (gasas). Un anillo oval = Babcock (vísceras).

## Verbrugge vs Maleolar
- **En común:** Ambas son pinzas de reducción ósea.
- **Diferencia visual:** Verbrugge: diseño para diáfisis largas. Maleolar: diseño para tobillo.
- **Diferencia funcional:** Verbrugge = fémur, tibia, húmero. Maleolar = fracturas de tobillo.
- **Error típico:** Usar Verbrugge en el tobillo.
- **Regla para recordar:** Diáfisis larga = Verbrugge. Tobillo = maleolar.
